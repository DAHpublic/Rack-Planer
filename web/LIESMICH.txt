Rack-Planer __V__ – Webversion (HTML/PHP)
=========================================

Läuft auf jedem Webserver mit PHP 7.4 oder neuer, z. B. der Web Station einer Synology.
Keine Datenbank, kein Docker. Gerechnet und gezeichnet wird im Browser; der Server
speichert nur.

Einrichten
----------
1. Den Ordner „rack-planer“ auf den Webserver kopieren (Synology: in den Ordner „web“).
2. Dem Webserver Schreibrechte auf den Ordner geben (Synology: Gruppe „http“ → Lesen/Schreiben).
3. Im Browser öffnen: http://<server>/rack-planer/
Ausführliche Anleitung für die Synology: SYNOLOGY.md im Repository (web/SYNOLOGY.md).

Daten
-----
  daten/schraenke/<id>.rack.json   je Schrank eine Projektdatei (inkl. Historie) – dasselbe
                                   Format wie die Desktop-Version, lässt sich dort öffnen
  daten/eigene-vorlagen.json       im Browser gespeicherte Vorlagen
Der Ordner „daten“ entsteht beim ersten Speichern. Zum Sichern genügt es, ihn zu kopieren.

Update
------
Automatisch: Jede Nacht zwischen 00:30 und 03:30 Uhr holt sich der Rack-Planer eine neue
Version vom GitHub-Release (braucht die PHP-Erweiterungen „zip“ und „curl“). Damit das
zuverlässig passiert, im Aufgabenplaner stündlich von 00:30 bis 03:00 aufrufen lassen:
  curl -fsS "http://localhost/rack-planer/api.php?p=autoupdate"
Programm und mitgelieferte Vorlagen werden ersetzt; „daten“ und einstellungen.ini bleiben.
Von Hand: Inhalt des neuen ZIP über den Ordner kopieren (Dateien ersetzen, aber
einstellungen.ini behalten), „daten“ nicht löschen. Mit web_update = true geht es auch im
Browser unter Hilfe → Programm aktualisieren.

Vorlagen
--------
Die mitgelieferten Gerätevorlagen stehen in vorlagen.json (eine Zeile je Vorlage, gleiche
Datei wie in der Desktop-Version) und kommen mit jedem Update neu. Eigene Vorlagen legt man
im Programm an („Als Vorlage speichern“); sie liegen in daten/ und bleiben bei Updates erhalten.

Einstellungen
-------------
einstellungen.ini (Erklärungen stehen in der Datei):
  auto_update = true        nachts automatisch aktualisieren
  web_update = false        Update von Hand im Browser
  server_speichern = true   false: der Server speichert nichts, Schränke als Datei speichern
Updates überschreiben diese Datei nie.
